# Configuration

A site is configured by `lighthouse.toml` at its root. Every key has a
default, so an empty file is a valid configuration.

Each key is listed in [Configuration keys](reference/config-keys.md). Themes
read their own section; see [Themes and layouts](guides/theming.md).
