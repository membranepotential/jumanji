# Lighthouse

Lighthouse is a small, fast static-site generator. It turns a folder of
markdown into a website you can host anywhere, and rebuilds only what changed.

New here? Start with [Getting started](getting-started.md), then
[install](installation.md) the binary and read about
[configuration](configuration.md).
